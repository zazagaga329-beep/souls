# Пепел

Промо-сайт о жанре soulslike в стилистике тёмного фэнтези. Проект состоит из главной страницы и отдельного каталога игр с описаниями, оценками и интерактивными профилями.

## Страницы

- `/` — история жанра, путь героя и интерактивный кодекс.
- `/games.html` — каталог Elden Ring, Dark Souls, Sekiro, Lies of P и Nioh 2.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Проверки проекта:

```sh
npm run lint
npm run build
```
